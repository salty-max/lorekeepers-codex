# Follow-up on the fourteen lore gaps

Review date: 5 October 2026. This follows the initial [entry review](lore-review.md).

All fourteen gaps received a targeted web search. Thirteen source gaps are closed by directly checking the relevant passage, or by correcting a claim that the passage does not support. Timber is an editorial exception: the named wolf is attested, but no canonical narrative was found. The user explicitly approved restoring its original hunter tale as flavour text without an in-entry label.

The novels below are original texts in third-party PDF reproductions, not publisher-hosted editions. Excerpts and publication details were cross-checked where available; this is not an edition-wide authentication. Chapter references are stable locators; PDF pages refer only to the linked reproduction. No book text is reproduced here. The Shadowfang history is the original introduction reproduced on Wowhead, not its modern comments or later dungeon lore.

Timber searches included the Classic NPC record, the Warcraft Wiki source route, and searches for the named wolf’s history. Results describing hunters’ personal experiences or invented roleplay were not admitted as Warcraft lore. Absence from this search is not proof that no text could ever exist. The original hunter tale is retained by explicit user request as flavour text, rather than recorded as source-verified lore.
